# 四联图实现说明

配置 `chart_enabled=false` 为默认关闭。开启后只对本条消息实际加载的 Spark 报告出图，所有原入口共享实现，无独立命令。跨消息配对记忆中的旧 Spark 不触发图表。

## 数据与计算

`telemetry.py` 按需读取解析 worker 中的完整 SamplerData；不会从前 120 项的模型概览重建数据。metrics 按累计 delta 还原绝对时间，缺字段时退回有可信起止的窗口；缺失/非有限/负数值不补成零。堆和 Ping 仅有快照时直接显示快照。最多处理 100 万个原始序列点，每条输出不超过 2,000 点；降采样保留桶内极值，不平均 P95。缺口桶中的极值以隔离标记展示，不跨缺口画连续线。

来源榜只选择明确的 `Server thread`。按池分组时还需 SPECIFIC dumper 且仅一个线程 ID；不选全线程合并根、最忙线程或 Folia 区域线程。使用 method→line→class 映射，排除 java/minecraft 与 Paper 生成帧，对 Carpet 整个 tick loop 包装帧遵从官方特例。一次 DFS 累计每个来源的最外层 inclusive；不同来源可重叠。同一来源嵌套不重复计时，不能把七个数值归一化为 100%。标题由明确平台名称/品牌决定；混合端使用中性来源标题。

范围：趋势可以来自保留 metrics，榜单来自保留调用窗口，池详情属于报告结束快照，GC map 属于报告提供的区间/JVM 全程。图中分别标注，不将全部来源数据都称作 profiler 活跃采样期。当前没有 GC 日志/JFR 输入，图 03 使用来源榜；无法确定主线程或映射时显示原因。

## Leaf 的有界一致性兼容

每个节点的全期间聚合仍须满足子调用合计不超父调用。只有 Java engine、interval>0，允许全报告累计局部窗口超额不大于 `min(interval_us/1000, 10)` ms。所有异常窗口 ID 写入 `window_consistency`；这些窗口可查询健康统计，但禁止任何带 self 的调用树查询。整段查询仍通过正常计算，不把局部负 self 截成零。async engine、多个误差合计超预算、全期间不一致、非法结构和资源超限都继续拒绝。

这一规则解决真实 Leaf 样本的一处 4 ms 窗口超额；不推断具体成因，不宣称所有同量级误差都无害。新增约束及错误窗口禁查均有测试。

## 私有导出与进程

`ReportSession.export_telemetry()` 通过固定的 `op=telemetry_export` 文件协议请求导出；LLM 查询工具不能调用该操作。worker 原子写固定 `telemetry.json`，限 2 MiB；主进程只复制到其创建的 chart 临时目录，随后关闭解析 worker，再启动独立 Agg 渲染进程。

渲染最多 30 秒，父进程每 0.2 秒检查总开关，取消/超时 kill 并 wait。沿用 1.5 GiB/更低继承地址空间限制；支持该限制的平台若设置失败，绘图失败而不阻断文字。Windows 无等价地址空间限制，仍执行时间、数据和输出边界。PNG 固定 2400×1500、限 8 MiB，发送前检查签名、IHDR 和尺寸。

Matplotlib 仅在子进程导入；主进程不依赖绘图库加载成功。渲染禁用 TeX/mathtext，报告标签清理控制字符、美元和反斜杠；symlog 数字标签使用普通数字格式，不执行报告文本。中文字体为包内 OFL 子集，不在线下载。

## 一次发送与生命周期

`chart_delivery.sqlite3` 的主键为完整统一会话标识 SHA-256 + 原始解码报告 SHA-256。只有成功发送图片才标为 sent；换人、文件名或 URL 不改变同内容身份。数据库不与缓存/历史共同过期，时区/配置重载也不重置 sent。

领取资格使用唯一键事务和 token。失败/取消释放未完成领取，初始化只恢复未完成领取；数据库不可读时不绕过判重。图片发送已成功但 DB 更新失败时，进程内集合防止当前进程重复并给出提示；重启丢失这次未落盘状态是明确的极端边界。多个插件实例共享同一数据目录不受支持，与原解析临时目录生命周期一致。

整个过程保留原有权限、单用户在途、重复报告和三份等待队列；没有分析模型仍使用原拒绝行为，不产生新触发方式。图表处理在同一 gate 内完成。模型失败但已成功加载报告时仍可交付开启的图表；图表失败不丢弃文字。

发送直接 await `event.send(event.image_result(local_path))`，不将即将删除的图片路径 yield 给外层。考虑适配器延迟读取，发送后仅保留 PNG 10 分钟，数值文件立即移除；到期、终止或重载清理。进程异常退出的残留在下次 initialize 清理。

## 验证范围

自动测试包含合成报告、真实 worker 导出与渲染、SDK 边界替身及发送状态。最低 AstrBot 4.16.0 wheel 中的 image_result / send 入口已作只读核对。用户提供的 NeoForge 1.21.1 与 Leaf 26.2 附件均通过实际进程解析、导出、绘图与发送替身验证；原始文件和身份不打包。

未在真实 QQ/NapCat 等适配器上运行；不能将本地发送替身验证描述为实际平台联调。当前不实现 GC 探针导入、任意单独绘图命令或重绘命令。
